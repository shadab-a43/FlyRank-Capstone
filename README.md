## Setup

1. Install [Node.js LTS](https://nodejs.org/)
2. Install [Git](https://git-scm.com/)
3. Clone this repository
4. Run `npm install`
5. Run `npm run dev` and open the URL Vite prints (usually `http://localhost:5173`)
