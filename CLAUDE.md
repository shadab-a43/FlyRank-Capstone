# Project instructions for AI assistants

This is a beginner FlyRank Front-end AI Engineering capstone.

## Who I am

I am new to professional frontend work. Explain clearly. Avoid jargon unless you also define it. Prefer small steps over large dumps of code.

## What this repo is for

A future responsive website (personal site, storefront-style site, or client-style site). Right now the repo is **setup only**.

## Stack we plan to use later

- React
- TypeScript
- Tailwind CSS
- Git + GitHub
- Cursor

Do not switch to a different stack unless I ask.

## Working rules

- Do not write application code unless I explicitly ask for it.
- Do not create extra files I did not request.
- Keep changes small and easy to review.
- Never add real API keys or commit `.env` files.
- If something is unclear, ask a short question instead of guessing a big design.
- When you change files, tell me what you changed in plain language.

## Quality bar (when we do write code later)

- Prefer readable code over clever code.
- Use semantic HTML and basic accessibility (labels, keyboard use, alt text).
- Check that layouts can work on mobile, not only desktop.
- I must understand the code well enough to explain it.

## Git

- Do not commit unless I ask.
- Use Conventional Commit messages when I ask you to commit (`docs:`, `chore:`, `feat:`, `fix:`).
